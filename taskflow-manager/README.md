# TaskFlow — Task Management Board

A responsive React + Vite Kanban-style task manager. Create, edit, delete, assign, search, filter, set priorities/due dates, and move tasks between To do, In progress, and Completed.

## Requirements
- Node.js 18+ (recommended: current LTS)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production
```bash
npm run build
npm run preview
```

## Notes
- Tasks are stored in browser `localStorage`, so they persist in the same browser.
- This is a frontend starter: team collaboration, login, notifications, and calendar sync require a backend and service integrations.
- The sample data can be restored using “Reset sample data”.
